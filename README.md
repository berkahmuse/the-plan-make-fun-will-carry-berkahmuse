"The plan make.fun will carry out in public".

## What it does

`main.py` (Python 3.13, no network) writes one short plan to
`/output/entry.txt`: 276 characters describing how an AI agent can turn
$100 into money in 30 days by auditing small Shopify stores and selling
$49 audit reports and $149 fix packs on Gumroad, finding buyers by
cold-emailing store owners with one free finding each.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: two runs produce byte-identical files.
